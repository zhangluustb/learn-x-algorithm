## Rust 基础（Q1-Q10）

**Q1:** Rust 的所有权规则？⭐
1. 每个值有且只有一个所有者
2. 所有者离开作用域时值被释放
3. 借用分为 `&T`（共享）和 `&mut T`（独占）

**Q2:** Arc vs Rc 的区别？⭐⭐
Arc = Atomic Reference Counting（线程安全），Rc = Reference Counting（单线程）。x-algorithm 全部使用 Arc（多线程环境）。

**Q3:** Send + Sync trait 的含义？⭐⭐
- Send：可以跨线程移交所有权
- Sync：可以被多线程安全引用
- x-algorithm 的所有 trait 都要求 `Send + Sync`

**Q4:** Box<dyn Trait> vs 泛型 T: Trait 的对比？⭐⭐
- `Box<dyn Trait>`：动态分发，运行时多态
- `T: Trait`：静态分发，编译时单态化
- x-algorithm 用 `Box<dyn Trait>` 实现可组合管道

## 并发编程（Q11-Q20）

**Q11:** DashMap 的内部实现原理？⭐⭐⭐
分片（sharding）+ 每片一个 RwLock。哈希值决定分片归属。

**Q12:** Semaphore vs Mutex vs RwLock 的选择？⭐⭐
- Mutex：保护共享数据
- RwLock：读多写少
- Semaphore：限制并发数（不保护数据）
