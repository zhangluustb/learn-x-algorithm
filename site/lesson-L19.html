X For You Feed Algorithm                              2024.xx - 2025.xx

  预测 19 种用户行为概率，端到端延迟 <250ms

详细版（4-5行）

X For You Feed Algorithm                              2024.xx - 2025.xx
技术栈：Rust / Python / JAX / gRPC / Kafka
• 架构：设计 Home Mixer 编排层，协调双路召回（In-Network + Out-of-Network）
• 模型：基于 Grok-1 适配推荐场景，实现 Candidate Isolation 注意力掩码，
  保证评分独立性和可缓存性
• 检索：实现双塔模型 + ANN 向量检索，从 10 亿候选中毫秒级召回 Top-1000
• 性能：bfloat16 混合精度推理，P99 延迟 <500ms

完整版（6-8行）

X For You Feed Algorithm                              2024.xx - 2025.xx
技术栈：Rust / Python / JAX-Haiku / gRPC / Kafka / DashMap
• 架构设计：主导 Candidate Pipeline 通用框架，支持 Source/Filter/Scorer 等
  6 大 Trait 的可组合管道，100% 组件可热插拔
• 排序模型：将 Grok-1 Transformer 适配为推荐排序模型，实现 GQA + RoPE +
  Candidate Isolation，19 维行为预测（含正/负面行为）
• 检索系统：设计 Two-Tower 检索模型 + L2 归一化 + Dot Product 相似度，
  配合 ANN 索引实现亿级帖子毫秒级检索
• 实时存储：用 Rust 实现 Thunder 内存帖子引擎，基于 DashMap 并发读写 +
  Kafka 实时消费，亚毫秒级 In-Network 候选获取
• 评分链路：PhoenixScorer → WeightedScorer → AuthorDiversity → OON，
  负面行为权重 -74x 确保安全内容优先
• 性能优化：bfloat16 推理降低延迟 40%+，Semaphore 背压控制，Zstd 压缩节省 70% 带宽

五、不同岗位方向调整

方向1: ML/推荐算法工程师

重点突出：Transformer 模型设计、多行为预测、Candidate Isolation、双塔检索、训练优化

方向2: 后端/系统工程师

重点突出：Rust 并发设计、gRPC 微服务、Kafka 消费、DashMap、管道框架

方向3: 基础架构工程师

重点突出：部署架构、监控体系、A/B 测试、热加载、性能优化

方向4: 全栈/应用工程师

重点突出：端到端系统设计、四大模块协同、API 设计、数据流
